# 分形文档规范

> 本文件定义分形文档的通用规范，适用于所有技术栈。

---

## _DIR.md

每个目录都要有一个 `_DIR.md`，用于说明：
- 这个目录负责什么
- 子目录如何分工
- 哪些文件是关键入口

要求：
- 内容使用中文
- 聚焦职责，不写重复的实现细节
- 目录结构变化时同步更新

---

## 文件头注释

关键源码文件使用如下格式：

```
/**
 * @input ...
 * @output ...
 * @pos ...
 */
```

要求：
- `@input`：文件依赖什么输入、上下文或上游模块
- `@output`：文件对外提供什么能力、结果或副作用
- `@pos`：文件在当前层级中的职责定位
- 使用英文短句

不同语言的注释语法：
- TypeScript/JavaScript: `/** ... */`
- Python: `"""..."""` docstring
- Go: `// @input ...`
- CSS: `/* @input ... */`

---

## 约束

- 单文件不超过 300 行
- 文档更新是实现过程的一部分，不是收尾动作
- 顶层结构变化时同步更新 `openspec/project.md` 的 Directory Structure
